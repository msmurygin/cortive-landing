Активация после отдельного одобрения

  1. В content/product-demos.json добавить реальные проверенные YouTube ID, подтвердить содержание каждой записи и заполнить stages только показанными шагами.
  2. Сохранить согласованные реальные кадры записей локально в /assets/demos/. Указать poster и исходные width/height, чтобы сохранить настоящий aspect ratio. Никаких придуманных thumbnails.
  3. Проверить доступность встраивания и субтитры в YouTube; выставить captionsConfirmed. Если есть transcript, добавить локальный файл и ссылку.
  4. Указать проверенный uploadDate в ISO формате только при известной реальной дате; duration необязателен и заполняется фактическим значением. Не использовать дату разработки вместо upload date.
  5. metadataVerified и publicationApproved разрешены только после отдельного founder gate. Выполнить node scripts/product-demos.cjs, проверить diff, preview и реальное mobile/desktop playback.

До заполнения approval и фактических полей build остаётся no-op. После активации HTML содержит local poster, сценарий, этапы, обычные ссылки и кнопку Load video player. Только нажатие создаёт iframe на youtube-nocookie.com; до этого нет player, thumbnail или preconnect-запросов к Google/YouTube. Звук не запускается автоматически. Отдельный Privacy review перед видео обязателен: privacy-enhanced mode не означает отсутствие обработки данных после взаимодействия.

VideoObject выводится только для одобренного видео с проверенным uploadDate, реальным local thumbnail и ID. Если даты нет, JSON-LD не выдумывается. Производные временные метки, примерные duration и несуществующие URL запрещены. Компонент готов; проверка реального воспроизведения ожидает реальные ссылки и не входит в блокеры стабилизации.

Источники технических требований

YouTube embedding and privacy-enhanced mode; Google Search Central VideoObject requirements.
