|---|---|---|
| Home | Early-stage/evaluation-only introduction obscured the implemented core | Standard operations on a configurable WMS, with customer work scoped separately. |
| Home configuration | Marketing focused on whether setup could be evaluated | Adapt forms, screens and process settings around the existing core; extensions where needed. |
| Product Overview | Procurement checks stood in for descriptions of what the product does | Inbound, inventory, outbound, RF and platform sections explain actions, users, handoffs and results. |
| Capability map | Whole map called conceptual, with generic availability qualifications | Implemented operations are distinct from project connections, advanced options and future AI. |
| Demo enquiry | Evaluation of an unspecified available build | Request a demonstration of core operations; same form, fields, consent and endpoint. |
| Vision | Autonomous go-live, one-day/two-week delivery, savings and security absolutes blended with current WMS | Current core remains current; AI-controlled configuration is future vision with no guaranteed duration, ROI or universal certification. |
| Assessment | Disclaimers sounded like uncertainty about the existence of Quark | Readiness describes the customer's preparation; specialist requirements still need validation. Questions, routing, scoring, schema and privacy boundaries do not expand. |
| Cost | Early-stage qualification undermined current capability | Budget describes software terms and customer implementation; no invented prices or ROI. |
| Website Terms / Privacy introduction | No product / intended-only product statements contradicted current core | Website and enquiry scope described factually. Existing collection, consent, retention, deletion, controller and legal clauses remain unchanged. |
| Shared footer | Product described only as an agreed evaluation scope | Configurable WMS for receiving, inventory and fulfilment. |

No new routes, modules, visual system or assessment capabilities. Existing head metadata stays byte-identical by founder instruction. The approval gate covers body copy, factual legal introductions and customer-facing report disclaimers. It does not authorise production deployment.
