Two ways to work.

Legacy terminal interface

Use a text session for scanning, quantities and task confirmation. The terminal client handles the connection and key input. Quark handles the warehouse task and its rules.

A device check covers the actual operating system, terminal client, character encoding and scanner configuration.

Check an MC9090 by configuration.

A model name is the start of the assessment. Zebra's archived documentation lists MC9090 devices with Windows CE and Windows Mobile configurations. Record the operating system and terminal software installed on your unit.

Zebra's archived device reference ↗

  1. Record the device. Note the model, OS version, scanner type, keyboard layout and terminal client. Include firmware and any client licence requirements.
  2. Check the session. Confirm the supported connection, character set, display size and function-key mapping. Plan authentication and network access with your IT team.
  3. Run the scans. Scan an LPN and a destination location. Test a wrong location, a duplicate scan and a barcode that contains leading zeros.
  4. Try the full task. Complete receiving or putaway on the unit. Check task confirmation, error messages and what happens when Wi-Fi drops and the session reconnects.
  5. Plan the rollout. Keep working devices where they meet the workflow. Budget for client software, batteries, maintenance and any replacement equipment.

Test a pallet movement.

Choose one pallet with an LPN and an available destination. The operator scans the LPN, scans the destination, then confirms placement. Check that the recorded location and task result agree with the physical move.
